# 文件格式处理

只在处理对应格式时读取本文件。

## 通用原则

原文件、渲染图、提取文字和分析裁切图分别保存；不要用裁切图替代来源文件。所有派生文件沿用稳定定位符，例如 `p003`、`slide-012`、`img-004`。渲染后核对总页数/总张数，记录失败项。

## JPG / JPEG / PNG

1. 记录文件名、像素尺寸和方向。
2. 先看完整图，再对文字、尺寸串、图例和目标区做局部放大。
3. OCR 只作为候选结果；回到像素核对 `0/8`、`1/7`、小数点、负号和单位。
4. 若聊天界面缩放导致小字不可读，使用原始分辨率或裁切查看，不依据缩略图猜测。

## PDF

1. 获取真实页数；逐页渲染为足够清晰的图像。
2. 同时提取文本层。扫描 PDF 无文本层时再 OCR。
3. 比较 PDF 页码、文档印刷页码和渲染序号，报告中优先写 `PDF 第 N 页`，可附印刷页码。
4. 复杂平面和尺寸页使用更高分辨率单独渲染；文字页可用普通分辨率。
5. 页面含嵌入大图时，若提取原图会丢失标注叠层或位置关系，仍以整页渲染为主。

如环境提供 PDF 专用 skill 或工具，使用它完成抽取与页面渲染，但本 skill 的证据分类、页码核对和空间判断规则仍然适用。

## PPT / PPTX

1. 保留幻灯片编号、标题、正文、讲者备注和对象内文字（可提取时）。
2. 每张幻灯片都渲染为图片；仅解析 XML 或正文会漏掉组合图形、框线、箭头、图片内文字和空间关系。
3. 检查隐藏幻灯片、母版/版式上的关键信息、被遮挡对象和裁切图片。
4. 对同一展项的连续幻灯片视为一个证据组，但每条证据仍指向具体幻灯片。
5. 旧式 `.ppt` 若不能可靠打开，优先请求原作者导出 PDF 或 PPTX；不要用文件扩展名推断内容完整。

如环境提供演示文稿专用 skill 或工具，使用它读取与渲染演示文稿，再按本 skill 进行空间分析。

## CAD 截图

- 先辨认单位、图名、楼层、比例、北向、轴网、图例和修订版本。
- 读取尺寸标注时同时记录尺寸线端点。附近出现多个数字时，不按距离最近原则强行配对。
- 区分绘图尺寸、坐标、标高、编号、文字高度和软件界面数值。
- 若截图裁掉了尺寸端点、比例尺或图名，记录为不完整证据。
- 框选区域可能是审阅标记、选择框、图层边界或展项范围；需由标签或上下文确认。

## SketchUp 与渲染/透视截图

- 检查相机透视、广角畸变、剖切面、隐藏对象、阴影设置、模型坐标轴和版本差异。
- SketchUp 的测量标签可作为显式尺寸，但要确认其端点和单位。
- 不使用近大远小的画面直接量长度；多视角匹配优先依赖稳定锚点。
- 渲染中的光照用于判断视觉倾向和风险，不用于输出真实照度。

## 推荐最小输入集

单展项若要形成较可靠的空间判断，优先索取：带目标标记的总平/局部平面、至少一张带尺寸图、入口或主流线方向、两个互补视角、目标区周边无遮挡图、版本或日期。缺少其中任一项不等于不能分析，但要降低相应结论置信度。
